# DevOps Monitoring & CI/CD Pipeline

## Overview

A DevOps learning project focused on containerization,
CI/CD automation, metrics monitoring, and service health
monitoring using Docker, Jenkins, Prometheus and Grafana.

## Technologies

- Linux
- Git
- Docker
- Jenkins
- Prometheus
- Grafana
- Bash

## Features

- Containerized DevOps services using Docker
- Jenkins-based CI/CD workflow
- Prometheus metrics collection
- Grafana monitoring dashboards
- Linux service health checks
- Basic log analysis and troubleshooting

## Architecture

GitHub → Jenkins → Docker
                  ↓
              Prometheus
                  ↓
               Grafana

## Learning & Implementation

I configured and tested the monitoring environment,
studied the interaction between Jenkins, Prometheus and
Grafana, and practiced Linux-based service monitoring,
container troubleshooting and basic automation.

## Troubleshooting

The project was tested using Linux and Docker commands
including:

- docker ps
- docker logs
- docker stats
- top
- free
- df

## Objective

To gain practical foundational experience in DevOps
monitoring, CI/CD, containerization and first-level
infrastructure troubleshooting.
